# Installing MacPuTTY
> [!TIP]
> If you do not want to follow the steps below, download `MacPuTTY-1.0.0-arm64.dmg` directly, but for development concerns, it is best to follow through with the steps below.

- Clone the repository:
```
git clone https://github.com/ayaans16/MacPuTTY
```
- Run the following command:
```
make dist
```
- Go to `dist/mac-arm64` and download the `.dmg` file that is created
